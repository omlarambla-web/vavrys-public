# Veřejný feed Vavrys

[Stáhnout poslední ověřený vavrys.xml](https://github.com/omlarambla-web/vavrys-public/releases/latest/download/vavrys.xml)

Soubor obsahuje veřejný importní feed Craft a Haglöfs včetně nákupních cen. Převodník a přihlašovací údaje jsou v odděleném soukromém projektu. Adresa vždy ukazuje poslední publikované vydání; předchozí vydání se nemažou.

Plán aktualizace: 07:00 a 20:00 Europe/Prague. Automatické publikování čeká na doplnění omezeného oprávnění FEED_PUBLISH_TOKEN v soukromém projektu. První zveřejněný soubor byl validovaný 13. 11. 2026 ráno.
